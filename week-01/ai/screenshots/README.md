# Screenshots — to be captured by hand

The lab requires **at least 3** screenshots from rocket.new. They cannot be produced from the CLI:
take them in the browser and drop the image files into this folder.

| # | What must be visible | File name to use |
| --- | --- | --- |
| 1 | The one-line prompt pasted into Rocket **and** Rocket's first reaction: the prompt-completeness score and the clarifying questions it asks | `01-prompt-and-score.png` |
| 2 | Rocket's **rewritten / enhanced** prompt, after its questions are answered | `02-rewritten-prompt.png` |
| 3 | The running preview with test data in it — use case B (`88, 47, -5, 101, abc, 73, 50, , 100`), it is the one that breaks things | `03-running-app-case-b.png` |

Optional but worth it: a 4th screenshot of the app on case D (`abc, , xyz`), and a 5th of the result
of the follow-up fix prompt.

Copy Rocket's questions and its rewritten prompt into `../prompts.md` as you go — the screenshots
alone do not satisfy the deliverable.
